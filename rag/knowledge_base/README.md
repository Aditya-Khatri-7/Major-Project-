# Knowledge base notes

These notes are the retrievable evidence for RAG layers 1 (literature) and 2 (generator fingerprints).
They are short drafts written from general knowledge of each paper or generator family. **Before you
cite any of them in your report, check the claim against the original paper and edit the note.**
Add your own notes as `.md` files under `literature/` or `fingerprints/` with a front-matter block:

```
---
modality: text | image | general
---
```

Then run `python rag/ingest.py --kb-dir rag/knowledge_base`. This README is not ingested.
