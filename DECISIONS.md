# Decision log

Changes to the locked design in ARCHITECTURE.md, and why. Add a line here whenever you change a decision.

| Decision | Choice | Why |
|---|---|---|
| Checkpoint / early-stopping metric | Validation **ROC-AUC** (configurable `--monitor`), patience 3 (text) / 4 (image), max 20 epochs | You asked for "keep improving until no better result". AUC is threshold-free and robust; loss can rise while ranking still improves (your first image run). Temperature scaling repairs calibration afterwards. |
| Calibration data | Text: dedicated `calib` split of HC3. Image: deterministic 40% of `valid/` never used for early stopping | Early-stopping data must not also tune thresholds, weights and temperatures. |
| Score caching | Every tool runs once per sample; ablations, fusion and thresholds computed offline | Cuts API cost and makes all ablation rows consistent. |
| Threshold band | `t_lo`/`t_hi` from precision/NPV targets, at least +/-0.05 around the F1-optimal cut | Guarantees borderline scores are flagged even if validation data separates perfectly. |
| Text DL weights format | HF directory `models/text_dl/` (`TEXT_DL_MODEL_PATH`) instead of a single `.pt` | Saves tokenizer and label map with the model. |
| Image weights | `models/efficientnet_b4.pt` + `.meta.json`; loader falls back to the legacy `efficientnet_b4_wilddeepfake.pt` | Old weights keep working (class order fake=0, real=1). |
| DeBERTa loading | Fallback to `refs/pr/4` safetensors when the main-branch pickle cannot be loaded (torch < 2.6) | Avoids forcing a torch upgrade. |
| RAG effect on the verdict | None on the score; a human-verified contradicting neighbour (similarity >= 0.85) forces escalation | Keeps the ablation clean; RAG grounds and audits, it does not silently move scores. |
| Reflexion | At most one judge re-run, only if two or more tools are usable and disagree (spread > 0.35) and a working judge plus API key exist | Bounded cost, demonstrable loop. |
| Chroma telemetry | Disabled | No data leaves the machine. |
| Case memory content | Verdict and tool explanations only, never the analysed text | Privacy. |
| Text DL model (changed) | **DeBERTa-v3-base** trained on `mix_train.csv` (HC3 24k + MAGE 60k + RAID 52k) at `models/text_dl_v2` | v1 (v3-small, HC3 only) memorised HC3 style: MAGE AUC 0.66. v2: MAGE 0.97, RAID unseen generator 0.96. Hardware is an RTX 5080 16 GB, so the base model (~1.5 GB inference) fits easily. |
| Text input normalisation | NFKC + zero-width strip + confusable->ASCII (only for mostly-Latin text) before tokenizing | RAID homoglyph attack: AUC 0.72 -> 0.99 with no retraining. Tamper counts are surfaced as evidence. |
| Text test sets | Use `raid_test_all`, `raid_unseen_gen`, `raid_unseen_attack`, `mage_test`, `hc3_test` | Old `raid_adv` / `raid_crossgen` overlap the v2 training mix (361 / 248 texts). |
| Image training data | Multi-source mix: WildDeepfake + FF++ (Deepfakes, FaceSwap, NeuralTextures) + Celeb-DF official Train | Single-source training gave FF++ AUC 0.52. FF++ frames are now face-cropped like the other sets. Test sets are video-disjoint; Face2Face + FaceShifter are never trained on (unseen-manipulation test). |
| Judge provider (Oct 4) | `LLM_PROVIDER=anthropic\|gemini`; Gemini called over REST with httpx (`agents/gemini_client.py`), same interface as the Anthropic client | The judge key available to the project is a Gemini key. No new SDK, so the tested environment is unchanged. Judges stay optional. |
| Image calibration refit (Oct 4) | Re-scored the 2000-image calibration split with the unified CLIP probe and refit temperatures, weights, thresholds (`t_lo` 0.35 / `t_hi` 0.50) | The previous calibration was fitted to the retired CLIP probe. Held-out image benchmarks were rerun afterwards. |
| Binoculars weight cap (Oct 4) | `text_slm` weight capped at 0.10 (`calibrate.py --weight-cap`); text thresholds refit | On the calibration split Binoculars lowers fused AUROC at every weight (0.9947 without it, 0.9886 at the old weight 0.51). Kept at 0.10 as an independent second opinion for disagreement detection: costs 0.003 AUROC. |
| Sole-detector rule (Oct 4) | For non-face images the general probe is the designated sole detector; a decisive verdict (confidence >= 0.5, capped 0.8) is not force-escalated | Without a judge key every AI-art image used to be escalated because only one tool is usable by design. Uncertain verdicts and lone face tools still escalate. |
| API hardening (Oct 4) | Optional `API_KEY`, per-client rate limit (30/min), 503 on a busy queue, optional upload retention (`JOB_RETENTION_DAYS`, default off), knowledge base auto-ingested on start | Uploads were kept forever, the endpoint was unauthenticated, and a fresh Docker volume had an empty RAG store. Retention is off by default so nothing is deleted unless the owner opts in. |
| Runtime dependencies (Oct 4) | `scikit-learn`, `joblib`, `httpx` added to `requirements.txt`; ranges follow the tested environment; exact pins in `requirements-tested.txt` | The CLIP probes are scikit-learn models: the API image would have crashed on any image request. Old pins (`chromadb==0.5.20`, `numpy<2`) did not match the environment the data was produced with. |
| Web interface (Oct 4) | Custom HTML/CSS/JS in `web/`, served by FastAPI at `/` (Streamlit client kept as optional) | Streamlit cannot be restyled into a professional case-report layout. Static files need no build step or extra container; all model output is inserted with `textContent` (no HTML injection). |
| Gemini quota handling (Oct 4) | On a daily-quota 429 the client fails fast and skips further calls for up to 10 min | The free key allows 20 requests/day/model; five retries with backoff added about 30 s to every request after the quota was gone. |
| Judge weights (Oct 4) | `text_llm` and `image_vlm` weight 0.3 (not fitted) | Judges could not be calibrated (quota). On the demo deepfake image the vision judge answered "authentic" with 85% confidence; a weight of 1.0 would let it override both image detectors. 0.3 lets a judge disagree (triggering Reflexion and referral) without dominating the score. |
| Docker model path (Oct 4) | Compose uses `models/text_dl_v2` | It still pointed at the retired v1 DeBERTa-small. |
| Model folder (Oct 4) | Release set kept in `models/`; experiments, `*_last.pt` checkpoints and v1 models moved to `models/_archive/` (not deleted); see `docs/MODELS.md` | Eight image variants and 4 GB of optimizer checkpoints made it unclear which model is final. |
| Architecture document (Oct 4) | `ARCHITECTURE.md` rewritten to match the code; original plan archived in `docs/` | It was marked LOCKED but described DeBERTa-small, a 3050, two image tools and no scope guard. |
